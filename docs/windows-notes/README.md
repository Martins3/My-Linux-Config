# 从 vn 无损迁移的 Windows 原始记录

本目录保存从 `~/data/vn/docs/windows` 移出的原始文档，内容按迁移前版本逐字保留：

- `setup-env.md`：环境搭建、字体、终端、OpenSSH、桌面和包管理记录。
- `pwsh.md`：PowerShell 命令与工具记录。
- `vs.md`：Visual Studio 和 MSBuild 记录。
- `why.md`：使用 Windows 作为开发机的背景。

上级目录的 `windows.md`、`windows-powershell.md` 等文件是重新整理后的入口，不替代这里的
原始记录。保留本目录是为了让迁移可以核对，避免整理过程中丢失命令输出、链接、待办或
当时的判断。
